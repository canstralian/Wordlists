# Canstralian/Wordlists

A collection of wordlists for **authorized security testing, defensive research, training, and education**.

## Scope

These files may contain passwords, phrases, identifiers, or security-testing material. Use them only where you own the target system or have explicit permission to test it.

## Dataset description

The repository contains wordlists intended to support activities such as password-strength assessment, security-tool testing, lab exercises, and defensive research.

Provenance, freshness, completeness, and suitability may vary between individual files. Consumers should inspect each file and its history before relying on it.

## Intended uses

Appropriate uses include:

- password-policy and resilience testing in authorized environments;
- defensive security research;
- training labs and CTF-style exercises;
- testing parsers, filters, and security tooling.

## Out-of-scope uses

Do not use these materials to gain unauthorized access, target third parties without permission, or violate applicable law or policy.

## Limitations

Wordlists age quickly and may include biased, offensive, duplicated, irrelevant, or context-specific entries. Presence in this repository does not imply endorsement, correctness, or suitability for a particular target.
